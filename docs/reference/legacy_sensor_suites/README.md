# Legacy Sensor Suite References

This directory preserves reference material for sensor suites that are not active on this NUC.

Active hardware on this machine is only:

- RealSense D455
- FLIR Boson
- Robosense M1
- Robosense Helios

The files under this directory are archived for parameter reference only. They are not desktop shortcuts, active launch entries, or maintained pipeline commands for the current machine.

Archived references include:

- RGB-left/right + thermal-left/right Kalibr notes and intrinsics.
- Mid360/Livox FAST-Calib notes and YAML examples.
- Livox Horizon launch examples.
- Original FAST-Calib Livox/AVIA scene_torch examples.
- Original thermal stereo left/right config.
- Original Livox distance-filter helper.

Do not add new runnable shortcuts for these references unless the corresponding hardware is physically installed on this machine again.
